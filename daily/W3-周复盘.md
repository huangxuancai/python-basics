**自评（1-5）**：4

**最大的收获**：

```
1. 从"会写代码"跨到"懂测试"。七种黑盒方法不是背出来的，是在登录用例里用出来的：
   锁定机制4条=判定表、验证码生命周期=场景法、SQL注入/XSS=错误推测、长度校验=边界值
2. 学会了"不硬凑"：输入校验重复模板用等价类表声明覆盖，比抄18条更有方法论价值。
   这个判断是我自己提出的，AI认可了——说明开始有测试设计的取舍意识
3. 学会了"分批计划"：没学过的知识（抓包/越权）不硬编，建占位sheet排到W4。
   真实项目的测试计划就是这么排的
4. 预期结果可判定这条纪律贯穿全周：从Day5改错练习到Day7的030重写，
   "登录成功""提示明确"这种模糊词已经能条件反射地识别出来
```

**最大的问题**：

```
1. Excel操作不熟练拖慢节奏：转置建表、单引号被吃、白字粘贴、忘保存，
   四个坑合计浪费约1小时。工具熟练度也是生产力
2. Day1-Day2纯理论日的录音练习执行得不够严格，部分自测题没有真正"合上讲义说一遍"
3. 用例编号漏填6条、所属模块漏填7条——批量写用例时的字段完整性检查还没形成习惯，
   靠AI验收兜底不是长久之计，W5自动化时要写脚本自查
```

**下周只改一件事**：**写完一批用例先自查再送验**——编号连续、模块非空、预期无模糊词，三项过一遍只要2分钟，能把返工轮次砍半。

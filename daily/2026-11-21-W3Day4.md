# 2026-11-21（W3 Day4 · 黑盒方法 2）


**做了什么**：学习判定表、因果图、场景法、正交实验法、错误推测法；四个练习全做并对照答案；七种方法速查表默写

**卡住的地方**：

```
1. 因果图和正交实验法不太熟悉
   → 不需要精通。因果图 = 判定表的草稿纸，知道四种约束名称（互斥/包含/唯一/强制）就够；
     正交实验法 = 用数学挑最少组合实现两两覆盖，实际用工具生成，知道原理就够
2. 判定表的合并规则一开始不会做
   → 关键：某个条件为 F 时如果结果已经确定，其他条件标 "-"（don't care）。
     优惠券例子：C1=F → 不管 C2/C3/C4，直接不满足。16 种组合合并成 5 条规则
3. 错误推测法不知道"推测依据"怎么写
   → 每条补漏用例必须标注依据：并发/时序、空值/格式、状态切换、历史bug、特殊字符。
     不能只写"我觉得这里会出问题"，要说清为什么觉得
```

**学到的规律**：

```
- 七种方法选择顺序：等价类+边界值（必用）→ 场景法（有流程）→ 判定表（多条件）→ 正交（组合爆炸）→ 错误推测（最后补）
- 场景法是今天最实用的方法：基本流 + 备选流 + 异常流，Day7 登录用例大部分靠它
- 判定表的价值是合并规则：4 条件 16 种组合 → 5 条规则，靠 don't care 减少冗余
- 错误推测法是补充不是替代，永远在系统化方法之后用
- 因果图和正交面试只需一句话讲清原理，不用会画图/手算
```

**面试能用**：

- "黑盒测试除了等价类和边界值，还有五种方法。判定表处理多条件组合，因果图理清条件约束，场景法覆盖业务流程，正交实验法用最少组合覆盖多因素搭配，错误推测法凭经验补漏。实际工作中我最常用场景法加等价类的组合"
- "因果图是判定表的前置步骤，用来理清互斥/包含/唯一/强制四种约束，避免不可能的组合"
- "正交实验法用于兼容性测试等组合爆炸场景，用正交表实现两两覆盖，实际用 Allpairs 等工具生成"
